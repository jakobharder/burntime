# Burntime

Burntime is a remaster and expansion of Max Design's 1993 strategy game 'Burntime'.
It recreates the original game with remastered graphics and modern platform support, while also adding new and expanded gameplay.

- [Project on GitHub](https://github.com/jakobharder/burntime)
- [Burntime.org Forum](http://www.burntime.org)

## Get Latest Version

You can check for the latest version on [GitHub Releases](https://github.com/jakobharder/burntime/releases).

## Cheats

Type `/petko` on the world map to choose one cheat action: instant travel,
refill food, water and health, or spawn useful items at the current location.
Each invocation grants one action. Using an action permanently marks the save
as having used cheats.
