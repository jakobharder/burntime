# Generated item candidates

These are new 32×32 inventory-item candidates designed to sit alongside the
original sprites in `gfx/original/items`.

Each final PNG uses a pure black background and only RGB colors found in the
original item set. The `source` directory contains the larger ImageGen renders
used to derive the pixel-sized candidates. `preview.png` is a nearest-neighbor
contact sheet for visual review.

Items:

- `item_crowbar.png`
- `item_canteen.png`
- `item_medicine_tin.png`
- `item_binoculars.png`
- `item_hand_crank_flashlight.png`
- `item_matchbox.png`
