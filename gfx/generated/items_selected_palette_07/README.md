# Selected gameplay items — colorful palette-7 treatment

Final 32×32 candidates for the selected gameplay items. Every output color is
present both in palette 7 and in the original `gfx/original/items` sprites.
The sprites deliberately use separated muted violet, olive, ochre, cream, green,
steel, and red regions rather than monochrome gray or pervasive rust.

| Sprite | Intended role | Suggested construction |
| --- | --- | --- |
| `item_tripwire_alarm.png` | Camp alarm / danger prevention | wire + batteries + electrical odds and ends + tin |
| `item_water_filter.png` | Water-hazard prevention | broken pump + hose + rags + tin |
| `item_cooking_pot.png` | Camp food improvement | tin + iron pipe + screws |
| `item_medical_pouch.png` | Healing equipment | rags + water bottle + tin |
| `item_sewing_kit.png` | Clothing repair/crafting tool | wire + rags + woodpile |

The `source` directory contains the larger ImageGen renders. `preview.png` is a
nearest-neighbor contact sheet of the final sprites.
